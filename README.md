# Circuleather

1. Install VS code -> https://code.visualstudio.com/
2. Install Docker -> https://www.docker.com/
3. Instal Github Desktop -> https://desktop.github.com/download/
4. Clone this repository to the Github desktop
5. Open the repository in VS code.
6. Open the terminal in VS code.
7. Type "docker compose up --build" and then press enter.
8. Start your container in the Docker app.
9. Open your browser and type : http://localhost/circuleatherinlog.php
